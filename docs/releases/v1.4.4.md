- Windows 自动读取系统 HTTP 代理与例外规则，切换代理后，后续请求会刷新配置。

- Android、iOS、Windows 和 macOS 的图标资源统一为书本与播放符号设计。本次提供 Android、iOS 和 Windows 安装包。

Android 更新时请选择与当前安装版本相同的架构；常见手机使用 arm64-v8a。Windows 请完整解压后运行。iOS 提供未签名 IPA，需自行签名安装。
